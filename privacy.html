プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-13

日本語

  • 本アプリ（Hermes Personal Assistant）は、開発者本人が自分の Google アカウントのデータを利用するための個人用アプリです。
  • Google API から取得したデータ（メール、カレンダー予定、ファイル等）は、利用者本人の PC 上でのみ処理・保存され、開発者を含む第三者のサーバーへ送信・共有・販売されることはありません。
  • OAuth トークンは利用者の PC にのみ保存されます。Google アカウントの「サードパーティ アクセス」設定からいつでもアクセス権を取り消せます。
  • Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。
  • お問い合わせ: https://github.com/hrasen

English

  • Hermes Personal Assistant is a personal application used only by its developer to access their own Google account data.
  • Data obtained through Google APIs (email, calendar events, files, etc.) is processed and stored only on the user's own computer. It is never transmitted to, shared with, or sold to any third party, including the developer.
  • OAuth tokens are stored only on the user's computer. Access can be revoked at any time from the Google Account "Third-party access" settings.
  • Hermes Personal Assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Contact: https://github.com/hrasen
